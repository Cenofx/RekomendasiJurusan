# 🎓 Sistem Rekomendasi Jurusan Kuliah

Sistem rekomendasi jurusan kuliah berbasis web yang membantu siswa menentukan jurusan terbaik berdasarkan nilai akademik, minat, gaya belajar, dan kepribadian.

## ✨ Fitur

- Input data akademik siswa
- Analisis nilai mata pelajaran
- Rekomendasi 3 jurusan terbaik
- Tampilan dashboard modern premium
- Responsive UI
- Sistem scoring sederhana
- Ranking hasil rekomendasi
- Detail skor kecocokan jurusan

---

## 🧠 Algoritma

Sistem menggunakan metode scoring sederhana:

- Nilai akademik
- Minat siswa
- Gaya belajar
- Kepribadian

Setiap jurusan diberikan skor berdasarkan kecocokan data siswa.
